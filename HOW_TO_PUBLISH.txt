PUBLISHING ON THINK SRIRAM

1. Start the site with npm run dev -- --hostname localhost --port 3000.
2. Open http://localhost:3000/studio. Enter a title, topic, summary, and essay.
3. Save draft to come back later. Preview essay to check the rendered body.
4. Choose Publish to local archive, then Confirm publish. This creates an
   MDX file in content/essays and lists the essay in the local Writing archive.
5. Open the local essay to check it. Deploy the new MDX file through the
   existing website hosting workflow. If the host deploys from Git, commit
   and push the new essay file along with any site changes that are needed.
6. Check the real public page. In Studio, select the essay, then copy the
   permanent link or edit and copy the starter text for LinkedIn, Substack
   Notes, or X. Post that short text yourself. The full essay lives on
   Think Sriram.

Drafts stay in .studio-drafts on this computer. This folder is ignored by Git.
Keep a private backup if you want draft copies on another computer. Studio is
available on localhost during development. Published files belong in your
website repository and appear in Writing, Topics, RSS, and the sitemap.
Keep the URL slug unchanged when you revise a published essay. Edit the
existing MDX file directly to revise it.

MANUAL PUBLISHING

You can still place a UTF-8 .txt file in content. Put the title on the first
line, leave a blank line, and add the body. The filename becomes the URL slug.
For a fixed date, start the filename with a date such as 2026-10-16. Keep
unpublished text outside content or use an underscore prefix, such as
_unfinished-note.txt.

Existing MDX files and URLs remain supported. A draft or scheduled status, or
a future date, keeps MDX content out of public pages. Markdown headings,
paragraphs, lists, emphasis, and HTTPS links are supported. Optional MDX
fields include genre, editorialNote, sources, updatedAt, correction, series,
and seriesOrder. An entry in sources can be a URL or "URL | Link label".

For a new essay, write a short summary asking the question the essay answers
or giving readers one reason to click. Use that summary as a starting point
for short social posts, then link to the canonical article on thinksriram.com.
